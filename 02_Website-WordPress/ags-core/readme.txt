Adithya Group of Services platform for agservices.in.

== Description ==

* Directory listings (hospitals, shops, offices) with verified status and last-checked date.
* Service providers with sign-up, verification and a provider dashboard.
* Service requests from customers, with reference numbers, tracking and a status timeline.
* Requests board for the team: assign providers, update status, record amount and commission.
* Leads CRM for the tech site and courses (form + REST endpoint).
* Team alerts by email and Telegram, WhatsApp button.
* Srikakulam district mandals and default service categories created on activation.
* REST endpoint for sklm.in: /wp-json/ags/v1/listings

== Installation ==

1. Upload the ags-core zip in Plugins > Add New > Upload Plugin and activate.
2. Pages are created automatically: Request a Service, Track Your Request, My Requests, Provider Dashboard, Join as a Provider, Srikakulam Directory.
3. Go to AGS > Settings and fill team email, WhatsApp number and (optional) Telegram bot.
4. Settings > Permalinks > Save once.
