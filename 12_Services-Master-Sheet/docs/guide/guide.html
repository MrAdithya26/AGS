2. What you need

  • The shop's Google account (Gmail). Use the same account every time.
  • A PC or laptop with Chrome for the one-time setup.
  • The folder 1-Install from this package (5 files).
  • About 20 minutes. No payment is needed.

3. Install step by step (one time)

A. Create the Google Sheet

1
Open sheets.new in Chrome (signed in with the shop account). Rename the sheet AGS Services Master.
2
Menu Extensions › Apps Script. A code editor opens in a new tab.

B. Paste the 5 files

Open each file from 1-Install in Notepad, press Ctrl+A, Ctrl+C, and paste it into the editor:

File in 1-InstallIn the Apps Script editor
1-Code.gsClick Code.gs, delete everything, paste.
2-Index.html＋ › HTML, name it Index (no ".html"), paste.
3-Styles.html＋ › HTML, name it Styles, paste.
4-App.html＋ › HTML, name it App, paste.
5-appsscript.json⚙ Project Settings › tick Show "appsscript.json", open it, replace everything, paste.
3
Press Ctrl+S to save.

C. Run setup once

4
In the toolbar choose the function setup and click ▶ Run.
5
Google asks for permission: choose your account › Advanced › Go to project (unsafe) › Allow. ("Unsafe" only means you wrote the script yourself. Data stays in your account.)
6
Go back to the sheet. You now have 9 tabs, about 75 services, release dates and message templates.

D. Publish the dashboard

7
Deploy › New deployment › ⚙ › Web app. Execute as: Me. Who has access: Anyone. Click Deploy.
8
Copy the Web app URL (ends in /exec). This is your dashboard link. Send it to yourself on WhatsApp.
"Anyone" only lets people see the login page. Nothing opens without a name and PIN.

E. First login

9
Open the link and log in with Admin / 1234. Then go to Settings and change the PIN straight away.
10
Settings › Shop details: phone, address, receipt notes, IRCTC agent ID, receipt paper size. Users: add each staff member with their own PIN.

4. Open it on every phone and PC

Nothing is installed on the devices. Every device uses the same link and sees the same data.

  • Android: open the link in Chrome › ⋮ › Add to Home screen. It opens like an app.
  • iPhone: Safari › Share › Add to Home Screen.
  • PC: open the link and bookmark it (Ctrl+D).
  • Each person logs in with their own name and PIN. The login lasts 6 hours.

5. Optional extras

TTD Chrome extension (only on PCs where you book TTD)

  1. Unzip the file in 3-Optional-TTD-Chrome-Extension to a permanent folder, e.g. C:\AGS\ttd-extension.
  2. Chrome › chrome://extensions › turn on Developer mode › Load unpacked › choose that folder. Pin it.
  3. Dashboard › Settings › Create API key. Extension › Options › Google Sheet: paste the Web app URL and the key › Save & test.

SMS for customers without WhatsApp

  • Free: install "SMS Gateway for Android" (sms-gate.app) on a spare phone with a SIM pack, turn on Cloud server, enter its username and password in Settings › SMS.
  • Paid: Fast2SMS charges for every SMS, including tests, bulk SMS and automatic reminders.
  • Then Settings › Automatic reminder SMS: choose who gets it, the time and how many days before.
If you want zero cost, use the Android gateway, or just use WhatsApp. WhatsApp messages from the dashboard are always free.
Settings: shop details, extension link, SMS and automatic reminders.

6. How to use it every day

New booking or application

  1. Click New booking (top right) and choose the Department first. The form changes to fit it.
  2. Search the customer's family, or type name and mobile for a walk-in. Pick the service: price and service charge fill in.
  3. For applications, tick the documents received. For travel, fill route, class and passengers.
  4. Enter the amount received and click Create booking. The "received" message opens ready to send.
New booking: department first, then customer, service and documents.

Move the work forward

TypeButtons in the bookingCustomer gets
TTDAttempting · Booked · Not booked · Lucky dip · Paid, no ticketBooked details or refund message
Train / bus / flightBooked (PNR, seat, CNF/WL) · Not booked · CancelTicket details, journey reminder
ApplicationsApplied · In process · Ready · Delivered · RejectedApplication no, expected date, "ready to collect"
Counter workCompleted"Work completed" (optional)

After each step the right Telugu or English message is ready. Click Send on WhatsApp (or SMS), then it is marked as sent.

Application ready to collect: one click sends the Telugu message.

Quick sale (bills, recharge, AEPS, xerox)

Click Quick sale at the top, pick the service, enter the amount and payment mode, save. Tick "Print receipt" if the customer wants one.

Quick sale: one line, counted in today's income.

Travel bookings

Train booking with PNR, seat and CNF status, and the ticket message.

Receipts

Open any booking › Receipt › choose A4, A5 or 80 mm › Print / Save as PDF. Save as PDF to send on WhatsApp.

TTD release day

Release day board shows TTD requests in columns: Requested, Attempting, Booked, Not booked. Book on the TTD site with the extension, then mark the result.

Bookings list and filters

Search by name, mobile, booking no, PNR or train no. Filter by department, status, month and TTD login. Export to Excel or send Bulk SMS to the filtered list.

Reports and month end

Reports shows income by department, daily income (with quick sales), by service, by staff and by TTD login, plus the refund register. Received is all money taken in. Service income is only your charges on finished work.

Services & prices

Every service has its fee, service charge, documents needed and usual days. Edit them here; new bookings use them automatically.

7. Before you go live: checklist

  • Admin PIN changed from 1234. Each staff member has their own login.
  • Shop details filled: phone, address, receipt notes, IRCTC agent ID, paper size.
  • Services & prices: real fee, service charge, documents and days set for every service you offer. Services you don't offer set to Active = No. (The starter values are only samples.)
  • Release calendar: this month's TTD dates checked against the TTD announcement.
  • Optional: SMS gateway tested with "Send test SMS", then reminders switched on.
  • Print one receipt on your shop printer.
  • 2-Step Verification turned on for the shop's Google account.

8. Updating, backups and data safety

Installing a new version later

  1. Apps Script editor: paste the new files over the old ones (same 5 names).
  2. Run setup once (new columns are added; your data stays).
  3. Deploy › Manage deployments › ✎ › Version: New version › Deploy. The link stays the same, so no device needs changing.

Backups

  • Google Sheets keeps every version: File › Version history.
  • Export to Excel from Bookings or Reports once a month.
  • Every release of this system is kept in Google Drive › ABD Innovations › Adithya Group of Services › AGS Services Master (CRM), with full git history.

Data safety

  • The sheet holds customers' Aadhaar numbers. Never share the sheet itself. Staff use only the dashboard link and their own PIN.
  • ID numbers are masked on screen and never printed on receipts.
  • Never send the API key, SMS password or PINs on WhatsApp.
  • Book train tickets only on your authorised IRCTC agent ID. The system records bookings; it does not log in to or fill IRCTC, bus, airline or government sites.

10. తెలుగు సారాంశం

ఇది ఏమిటి?

AGS Services Master మన సెంటర్ పనులన్నింటికీ ఒకే సిస్టమ్: TTD దర్శనం / సేవలు, రైలు / బస్సు / ఫ్లైట్ టికెట్లు, ఆధార్, పాన్, ఓటర్ ID, సర్టిఫికెట్లు వంటి దరఖాస్తులు, బిల్లులు, రీఛార్జ్, జిరాక్స్. డేటా మొత్తం మీ Google Sheet లో ఉంటుంది. ఖర్చు లేదు.

ఇన్‌స్టాల్ చేయడం (ఒక్కసారి మాత్రమే)

  1. షాప్ Google అకౌంట్‌తో sheets.new తెరిచి, పేరు AGS Services Master పెట్టండి.
  2. Extensions › Apps Script తెరిచి 1-Install ఫోల్డర్‌లోని 5 ఫైళ్లను పై పట్టికలో చెప్పినట్టు పేస్ట్ చేయండి. Ctrl+S నొక్కండి.
  3. setup ఎంచుకుని ▶ Run నొక్కండి → Allow చేయండి.
  4. Deploy › New deployment › Web app (Me / Anyone) → వచ్చిన లింక్ మీ డాష్‌బోర్డ్.
  5. Admin / 1234 తో లాగిన్ అయి వెంటనే PIN మార్చండి. ప్రతి స్టాఫ్‌కు వేరే లాగిన్ ఇవ్వండి.
  6. ప్రతి ఫోన్‌లో లింక్ తెరిచి Add to Home screen చేయండి. ఏమీ ఇన్‌స్టాల్ చేయనవసరం లేదు.

రోజువారీ వాడకం

  • New booking → ముందు Department ఎంచుకోండి → కస్టమర్, సర్వీస్ ఎంచుకోండి → డబ్బు నమోదు చేసి Create నొక్కండి.
  • దరఖాస్తులకు పత్రాల జాబితాలో కస్టమర్ ఇచ్చినవి టిక్ చేయండి. తర్వాత Applied → In process → Ready → Delivered.
  • రైలు / బస్సు టికెట్ బుక్ అయ్యాక Booked లో PNR, సీటు, CNF/WL నమోదు చేయండి.
  • బిల్లులు, రీఛార్జ్, జిరాక్స్ కోసం Quick sale వాడండి.
  • ప్రతి దశ తర్వాత తెలుగు మెసేజ్ సిద్ధంగా ఉంటుంది → Send on WhatsApp నొక్కండి.
  • రసీదు కోసం బుకింగ్ తెరిచి Receipt → Print లేదా Save as PDF.
  • డాష్‌బోర్డ్‌లో Work queue చూడండి: రీఫండ్‌లు, ఆలస్యమైన దరఖాస్తులు, పంపని మెసేజ్‌లు, తీసుకెళ్లాల్సినవి.
  • నెలాఖరున Reports లో డిపార్ట్‌మెంట్ వారీ, రోజువారీ ఆదాయం చూడండి, Excel లో సేవ్ చేయండి.

జాగ్రత్తలు

  • Services & prices లో అసలు ఫీజు, సర్వీస్ ఛార్జ్ ముందుగా సెట్ చేయండి (ఇచ్చినవి నమూనాలు మాత్రమే).
  • Sheet ను ఎవరితోనూ షేర్ చేయకండి. ఆధార్ నంబర్లు అందులో ఉంటాయి.
  • Fast2SMS లో ప్రతి SMS కు డబ్బు పడుతుంది. ఉచితంగా కావాలంటే Android SMS Gateway లేదా WhatsApp వాడండి.
