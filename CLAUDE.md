# Working rules for this repo

- This is the single home for all AGS tech work. Put every app, code change and tech doc here.
- Log every change in `CHANGELOG.md` (date, what changed, plain English).
- Never commit secrets (`.env`, API keys, Supabase service keys) or personal data of customers, providers or devotees.
- Do not delete old versions; keep them alongside (e.g. `v1` copies) or rely on git history.
- Customer-facing pages must state AGS is an independent private service, not a government service.
- Audience: Telugu-speaking customers in Andhra Pradesh and Telangana; keep Telugu + English text in mind.
- The owner is a basic-level web user: explain changes simply, give copy-paste-ready steps.
